# 南方月赛赛程

男单 7 人全循环、男双 6 组全循环、混双两组各 5 对全循环后前二淘汰。赛程没有连打。胜场相同先看相互胜负，胜负套圈看总净胜分。

打开首页就是这场比赛。通用的 7 人单打轮转在 `/zhuan`。

# 七人转

7 人羽毛球单打轮转。场次对齐，休息匀开，手机上可以记分。

每人 3 场排不齐：7×3 不能被 2 整除。公平的场次是每人 4 场（半循环，14 场）或每人 6 场（全循环，21 场）。

- **3 片场**：全循环 7 轮，每轮 3 场同时打，1 人轮空。最快，几乎连打。
- **2 片场**：节奏最好。每轮 4 人打、3 人歇，最多连打 2 轮，最多连歇 2 轮。
- **1 片场**：每次有 5 个人在等。赛程保证不连打，两次上场之间歇 2 到 3 场。一个晚上用半循环、11 分。

半循环按水平从强到弱填名字时，每人避开相差最大的两位。

## 本地运行

```bash
npm install
npm run dev -- -p 4179
```

浏览器打开 http://127.0.0.1:4179 。

检查赛程是否公平：

```bash
npm run check
```

记分保存在本机浏览器里，刷新不会丢。
